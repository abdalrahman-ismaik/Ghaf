# AI assistance and team review

Ghaf has used substantial AI assistance, including implementation, tests, architecture and product
documentation, repository maintenance, and prepared media work. This repository does not represent
all code or documentation as independently student-authored.

The [assistance ledger](competition-readiness/ai-assistance-ledger.md) records specific work,
prompts, generated contributions, rejected suggestions and remaining reviews. The
[request history](competition-readiness/requests.md), feature specifications and Git history provide
additional context. The ledger explicitly notes that it is not a complete record of every earlier
prompt; missing history must be recovered from genuine records rather than reconstructed as fact.

The supplied SMAC 2026 orientation, pages 10 and 17, permits supporting AI with a report describing
prompts and contributions and prohibits AI generating the full application. Its page 13 assigns
10% to repository/development evidence and 25% to Q&A within the combined 35% category. This
disclosure does not certify competition eligibility or establish that the required human work
has occurred.

Each team member should document their actual contribution and review, explain the relevant code
and tradeoffs, and demonstrate changes they understand. Automated tests, commit-account names and
agent reviews do not establish student authorship or understanding. Named human review remains
pending wherever no direct record exists.

The September 13 repository cleanup was performed with Codex: test organization and quality gates,
then documentation relocation, local metadata cleanup and ignore rules. Those are AI-assisted
maintenance changes. Existing assistance evidence is retained; file organization does not change
the original authorship or the competition's disclosure requirements.
