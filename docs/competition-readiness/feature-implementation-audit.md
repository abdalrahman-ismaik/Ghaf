## Evidence and authority

The current explicit request establishes the acceptance criteria below. Earlier explicit approvals establish detailed rules where compatible. Historical proposals and document completion claims are evidence of intent/history, not runtime proof. Existing source and tests are inspected independently. New behavior requires an additive specification before source changes. No external operation or physical-device pass is inferred from mocks, a flag, or an installed screen.

Implementation status vocabulary: NOT LOCATED, MISSING, PARTIAL, IMPLEMENTED, VERIFIED, BLOCKED, DEFERRED/SUPERSEDED. Verification is separately recorded as documentation claim only, code inspected, automated checks passed, emulator/simulator checked, real device checked, two devices checked, or configured external service checked. Historical evidence is labeled by its source/candidate. VERIFIED here means the stated acceptance boundary was exercised, not production acceptance.

Root serializes tests and integration. Ownership and continuation: [session checkpoint](coordination/STATUS-IMPLEMENTATION-AUDIT.md). Status is assessed against each complete requirement: a passing local subfeature does not make its unimplemented synchronization/provider part VERIFIED.

These package declarations do not constitute performance or platform acceptance.

No maps/location, Google Calendar, allowance, call transport, notifications or billing implementation was located. Calendar icons and study civil dates are not integration evidence. Hosted messaging documentation reports additional foreground-location objects outside this checkout; they were not inspected or modified by this audit.
- Source CI is `.github/workflows/ci.yml`; isolated account Auth/SQL and messaging PostgreSQL checks are in `backend.yml`; manual internal APK generation is in `android-internal.yml`. Native scripts are `scripts/native/build-apk.ps1` and `.sh`. The native workflow uses Java 17, Android 36/Build Tools 36.0.0, NDK 27.1.12297006 and CMake 3.30.5. Existing [internal Android guide](../backend/internal-android.md) records the previous artifact, signing limits and actual device evidence; no fresh APK was produced here.
