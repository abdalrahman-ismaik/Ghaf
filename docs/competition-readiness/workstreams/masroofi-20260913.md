# Masroofi competition implementation

User request: implement the competition concept and a realistic UAE-influenced مصروفي card.
Contract checkpoint: `c9c0215`. Worktree began with an unrelated package-lock.json modification;
that modification is preserved and excluded from this slice.

## Scope

Feature 017 owns a pure in-memory simulation: private version-bound Parent promises, ages-10+
enablement/attestation, existing recognition-triggered credit, integer-fils ledger, guarded
Parent/Child views, prospective spending controls, two practice purchases and exact reset.
The card is original code-native geometry with shared botanical colors, dune engraving, a
gold-colored chip and a woven geometric edge. No imported/generated raster, external card brand,
real payment credential, provider or dependency is introduced.

Runtime boundaries: new Masroofi models/service/components/resources/config, registry/store,
Parent Family/Child Today/task entries and contextual routes. Existing Family Reward, Seeds,
garden, League and live/default-off flags remain independent.
