# Ghaf competition readiness package

Prepared September 12, 2026 on `redesign/ui-experiments`, from botanical baseline `55f9f2b`.
The selected direction is **competition-first**: a polished 2–3 minute local journey on the
primary Android, with independent installation and reliability checks on a secondary Android.
Four focused Codex sessions are recommended; the user's configured subagent capacity of 10 is
preserved. New product behavior in this package is a proposal requiring the corresponding Spec Kit
contract before implementation.

## Recommended order

1. Produce and directly test an installable Android candidate; resolve core UI/access blockers.
2. Specify and implement minimal restart-safe task/progress recovery and deterministic reset.
3. Make one useful recommendation and its true rationale clear, with honest prepared/live labels.
4. Complete Parent-confirmed action → authorized garden growth → one durable private memory leaf
   and a readable family timeline. Memory is currently unimplemented and needs an accepted story.
5. Freeze, rehearse the 2–3 minute journey and practice student Q&A. Repository/knowledge is 35%
   of the rubric, including 25% for Q&A.
6. Consider only a local agenda if the core passes and time remains. Study, money practice, Maps,
   Google Calendar integration, live synchronization and messaging stay later.

Preserve the living Ghaf identity and UAE landscapes. The recommended design candidate is
**Family Field Journal**: a strong garden composition, clear next action and personal editorial
memory treatment. Compare representative screens before selecting it; the catalog's imported
visuals are inspiration, not licensed app assets or implementation authority.

## What changed in the application

The bounded runtime correction makes Task Builder show only configured Child profiles, using
their current nicknames and age bands, with numeric bidi isolation and invalid-selection guards.
Six regression cases cover both locales and missing/excluded profiles. No new app feature,
network service, account system, payment, live Child media or default-off release flag was activated.

Three MCPs are configured and smoke-tested: Playwright, Sequential Thinking and Context7. Three
original Ghaf skills were added. Four account-dependent provider entries remain disabled. Existing
skills were preserved; raw installers and classroom credentials were not executed or imported.
See the tooling report before claiming that every bundled tool was installed.

All 13 design archives were extracted and inspected. Raw archives, extracted assets, browser
captures and tool logs remain in ignored local directories. The tracked reports summarize direct
evidence; this is not a claim that every Sketch screen was freshly rendered or every dependency
was executed. Embedded artwork has not been copied into the mobile bundle.

## Acceptance boundary

The automated baseline and the corrected profile path have passing evidence. A full browser
task/help/confirmation/growth journey was observed. Progress loss after reload remains a core gap;
saved family memory is proposed. No standalone APK, physical Android, named-human review or timed
live rehearsal has passed in this environment. Read the QA report for exact final counts and
platforms rather than treating this package as release approval.

The toolkit, bounded fix and planning artifacts are prepared for local integration. Student review,
new behavior implementation and physical demo acceptance are separate remaining work. No push,
main merge, deployment or submission was performed for this inspection package.
