## Purpose and composition

Provide the finite, no-fail illustrated route for `learning.mangrove_roots.v1`, titled
“بين جذور القرم / Among the Mangrove Roots.” Use a calm header, source disclosure, short ordered
story cards with local code-native habitat art, visible finite progress, one understanding check,
neutral retry explanation, completion state, and an equally prominent switch to the accessible
route. It recognizes that mangrove habitat supports coastal life and needs careful stewardship; it
never claims a real visit or measured impact.

## Data and completion authority

Entry requires station 132, the active Child profile/epoch, valid package ID, and the flag. Opening,
scrolling, elapsed time, and a wrong answer do not complete learning. The approved answer records
one idempotent completion event shared with the accessible route. Completion creates zero Seeds,
Garden, canopy, League, Challenge Leaf, or Family Reward progress. It may satisfy only the exact
badge criterion. The screen never calculates a task reward or autoplays another lesson.

## Navigation and recovery

Accept closed origins from Impact Path or eligible Badge Detail. Arabic Back is physically right;
return restores exact origin/station/badge/focus. Switching modes retains valid package progress and
origin. Save interruption resumes the same finite step; already completed resolves to a stable
summary. Locked, unknown-package, wrong-profile, invalid-origin, and flag-off links fall back to the
safe Child Growth root. Bottom navigation is omitted.

## States

Locked rejection, loading local package, ready, page/step progress, understanding check, incorrect
with neutral explanation/retry, submitting, completed, already completed, offline-ready,
interrupted/resumed, recoverable save error, unavailable illustration, and stories-disabled entry.
No timed response, autoplay, real media capture, GPS, browser, or live AI is permitted.

## Accessibility, motion, copy, and provenance

Semantic sections and text alternatives preserve the learning objective without imagery. Controls
are 48×48, progress is textual, focus follows content order, and 200% text scrolls naturally with no
horizontal overflow. No essential parallax or animation; reduced motion uses direct page changes.
Any future audio is optional, user-started, transcribed, and separately approved. Arabic/English
facts, sources, cultural/place wording, age comprehension, safeguarding, visual art, and route
equivalence require named human review before release activation.

## Acceptance

Prove station lock, exact package identity, finite progression, neutral retry, resume, shared
idempotent completion, zero-reward invariants, equal accessible credit, no autoplay/network/media,
profile/reset isolation, origin restoration, both locales/directions, and flag-off fallback.
