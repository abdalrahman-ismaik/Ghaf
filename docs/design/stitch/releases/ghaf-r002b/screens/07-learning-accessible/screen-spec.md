## Purpose and composition

Offer an equal-status concise route for the same Mangrove Roots objective when story sequencing,
imagery, motion, or reading demand is inaccessible or undesired. Do not call it remedial or lesser.
Use a plain-language overview, short fact list, optional Parent-guided discussion prompt, the same
no-fail understanding check, neutral retry, source disclosure, and completion summary. It must work
offline and without visual art, audio, timed input, complex gesture, or media permission.

## Data and completion authority

Use `learning.mangrove_roots.v1`, the same station-132 unlock, origin, profile/epoch progress, and
idempotency key as Story. Completing either route prevents duplicate credit from the other.
Switching retains valid progress. Completion awards zero Seeds and zero existing task consequences;
it may satisfy only the exact named badge criterion. Parent-guided copy is an optional method, not a
new Parent approval transaction.

## Navigation and states

Allow direct unlocked entry or a mode switch from Story. Arabic Back is physically right and exact
origin restoration is mandatory. Required states: ready, stories-disabled entry, partial progress,
check, incorrect/retry, submitting, completed, already completed by either mode, offline-ready,
package/source unavailable, interrupted/recovered, save error/retry, and large-text minimal layout.
Invalid role/profile/package/origin/flag returns to a safe Child Growth root.

## Accessibility, copy, and review

The entire route works with screen reader, switch/keyboard focus, 200% text, no motion, no time
limit, and no gesture-only control. Use headings, concise paragraphs, 48×48 actions, non-color state,
and an explicit “same completion credit” explanation. Arabic/English content, factual sources,
objective equivalence, cultural/place wording, safeguarding, and any Parent-guided language require
named review before release activation.

## Acceptance

Prove equal package and criterion credit, cross-mode idempotency, mode-switch progress retention,
zero reward/growth, no unsupported permission, profile/reset isolation, neutral retry, offline
recovery, origin restoration, RTL/LTR and large-text containment, and flag-off fallback. Canonical
