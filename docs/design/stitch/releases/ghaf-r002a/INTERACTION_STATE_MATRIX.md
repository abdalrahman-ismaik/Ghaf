## Global native requirements

- Safe areas and natural scrolling at 320, 360, 390, and 430 widths plus one wider viewport; 390×844 is a comparison viewport, not a canvas.
- Keyboard avoidance preserves the focused field and fixed-action clearance.
- Arabic physical placement: Help left, avatar right, mathematically centered root title, nested Back right, forward arrow left, checkboxes right, and Child navigation left-to-right الدوري | حديقتي | اليوم.
- English mirrors semantic direction, not hard-coded coordinates. Mixed script uses isolated data spans and tabular numerals.
- Touch targets are at least 48×48; primary Child actions are 56 high where specified. Normal text contrast is at least 4.5:1.
- Controls expose name, role, state, error, and busy semantics. Native sheets trap accessibility focus, restore it to the invoking control, support Back dismissal where safe, and never stack.
- A submission gives zero rewards. Only the existing Parent approval transaction creates its idempotent receipt.
