# Ghaf Growth Journey Prompt & Product Pack

This pack defines a refined Ghaf opening/onboarding experience and an ethical, game-rich progression
system for children called **مسار الأثر (Impact Path)**.

## Delivery status

This is a **research, specification, and prompt pack**. It supplies implementation instructions for
Codex and sequential screen-generation prompts for the existing Google Stitch project. It does not
claim that live Stitch screens, a connected prototype, exported assets, or production code have
already been created. Those outputs exist only after the prompts are run in their target tools,
reviewed, corrected, and verified.

## Files

- `GHAF_GROWTH_JOURNEY_RESEARCH_AND_SPEC.md` — researched product decision, progression economy,
  starter badge catalog, screen blueprint, data model, guardrails, and acceptance criteria.
- `CODEX_IMPLEMENTATION_PROMPT.md` — paste-ready master prompt for implementing and documenting the
  feature in the Ghaf codebase.
- `GOOGLE_STITCH_PROMPT_PACK.md` — sequential prompts for creating and wiring the opening,
  onboarding, Impact Path, Badge Gallery, badge detail, achievement moment, UAE story, and Parent
  progress screens in the existing Stitch project.
- `report-source.md` — source ledger with evidence, limitations, UAE content anchors, and rights
  cautions.

## Core decision

Copy the **clarity and anticipation** of a high-quality game pass, not its monetization or pressure:

- one free, cumulative path;
- existing Parent-approved Seeds as the only progression unit;
- deterministic, visible unlock criteria;
- permanent badges and evergreen chapters;
- private Child progress and cooperative community meaning;
- no purchases, random drops, streak loss, timers, public ranking, GPS check-ins, or FOMO.

## Recommended order

1. Review the research/spec and approve naming, the canonical badge registry, sample milestones, and
   P0 scope.
2. In Google Stitch, paste Prompt 00 once, then Prompts 01–12 one at a time; inspect and correct each
   generated screen before wiring the prototype.
3. Test the connected Stitch prototype with children and Parents before expanding the catalog.
4. Place the approved spec and screen decisions beside the implementation repository, then run the
   Codex master prompt and verify the resulting code and documentation.
5. Complete Emirati cultural/editorial, accessibility, privacy, and legal/IP review before commercial
   release.

## Canonical demo

Salem begins at **120 lifetime Seeds** with the current Mangrove stage completed. The first Impact
Path chapter, **العناية بالمياه والسواحل**, runs from 120 to 180 Seeds and previews deterministic learning,
cosmetic, mastery, place-story, and major chapter achievements.
