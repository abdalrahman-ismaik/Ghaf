# Prepared nature ambience

`nature-soundscape-v1.mp3` is a 48-second locally synthesized, non-verbal soundscape authored on
2026-09-07 with FFmpeg 7.1.1 from layered pink/brown noise and two quiet bird-like tonal accents.
It contains no downloaded field recording, speech, personal data, or third-party sample. It was
originally packaged with Ghaf's first-run presentation and is now the one app-wide foreground
ambience source.

Runtime playback is local and offline. One root-owned player loops the soundscape quietly, ducks
below prepared narration, pauses when Ghaf is inactive/backgrounded or a screen reader is active,
and follows the device-local Settings preference. App configuration keeps operating-system
background playback disabled. Playback never requests recording, microphone, notification, or
network access.

Source inspection cannot establish subjective naturalness, loudness, narration balance, or an
inaudible loop seam. Those qualities require a named human listening review on the authoritative
Android build.
