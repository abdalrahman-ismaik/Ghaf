# Quickstart: Parent Task Workspace

1. Run `npm run typecheck`, `npm run lint`, `npm run format:check`, and `npm test`.
2. With the feature flag off, complete the canonical Parent-to-Child recycling journey and reset.
3. With the candidate flag enabled in a development build, inspect Parent Tasks in Arabic and
   English at 320 and 390 dp: Create task, All Children, Child filters, category rail, template
   rail, current work, and prepared labels must remain findable.
4. Save bilingual wording, leave and reopen the builder, reuse it, then delete it. Confirm the
   journey and counters never change. Reset and verify the library is empty.
5. Enter Salem and Alya separately and confirm neither sees saved templates or sibling task detail.
6. Record physical Android and named product/cultural/accessibility review as PASSED, FAILED,
   BLOCKED, or NOT RUN. Do not activate release while required review is absent.
