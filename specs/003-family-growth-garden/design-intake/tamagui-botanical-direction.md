# Tamagui Botanical Direction

User accepted this direction through the 2026-09-11 request to start the proposed redesign.
Implementation is code-led using the existing approved artwork and native SVG geometry.

## Direction contract

- **Mode:** Operate. Parent and Child must understand their next action immediately.
- **World:** contemporary botanical family app; warm limestone, dark forest, measured amber,
  generous Arabic text, and UAE landscapes with recognizable Ghaf silhouette.
- **First viewport:** Parent Home pairs a personal greeting with an open family-canopy composition
  and pending work. Child Today places the current landscape beside a clear task focus. Garden
  gives the selected landscape room, with progress and its meaning grouped below it.
- **Structure:** use open sections, divided lists, and a few meaningful tonal panels. Avoid
  repeating equally weighted rounded cards or placing every label in a pill.
- **Signature interaction:** existing confirmed action leads to the event-owned Seed and landscape
  reveal. Press feedback lasts 120ms, status transitions 180ms; no perpetual decorative motion.
- **Cross-surface reach:** common controls, headers, forms, utility lists and overlays use one
  Ghaf token source mapped into Tamagui. Parent screens are composed; Child surfaces use more
  illustration and stronger task emphasis.
- **Accessibility:** logical RTL, Alexandria/Readex, 48dp actions, scalable unclamped essential
  text, focus indication and reduced-motion final states. Existing translations are authoritative.
- **Scope:** presentation only; no route, task, progress, access, consent, media or flag semantics
  change. Frozen token values remain as migration compatibility references.
- **Risk and evidence:** large text, keyboard and accessibility order need device observation.
  Browser captures cannot establish Android acceptance. Capture new evidence without replacing
  historical screenshots or claiming human review.
