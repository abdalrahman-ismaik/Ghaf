# Masroofi surface brief

Mode: Operate. Extend Ghaf's botanical world; this is a private, contextual money-practice
surface, not a replacement visual identity or a separate app.

2026-09-13 revision: the user rejected the green-dominant first card and requested a stronger UAE
identity plus fewer demo marks. The replacement has a pearl-to-sand ground, substantial red
woven panel, dark ink text, gold chip, crisp barjeel/skyline/coastal engraving and UAE flag accent.
The woven panel and flag preserve their physical orientation in both locales. These are original
SVG geometries inspired by UAE architecture/craft, not an authenticated traditional artifact or
official national/financial emblem. Native text carries the title, holder and Emirates label.

Application palette and typography are inherited from src/design/tokens.ts. The deliberately
multicolor card artwork owns its small scoped palette in src/design/masroofi.ts. Alexandria carries titles;
Readex Pro carries controls, names and tabular amounts. The card approximates physical-card
proportions at normal phone widths, expands for text, and keeps its holder name readable.
Decorative vectors are inaccessible; the visible title/holder text remains semantic.

Parent sequence: choose profile → card → activate or balance → fixed task reward → purchase
rules → practice funds → activity. Child sequence: card → available balance → earned credit →
finite practice shop → readable rules → activity. Eight wrapping category choices select a single
sample purchase, avoiding eight long product rows. Each of the eight Parent category switches is
independent. Native switches and explicit Save apply prospective controls. Amount choices and
Child selectors wrap; no horizontally scrolling controls.

Money is not drawn into the artwork. The visible balance is a native live projection below the
card. A single concise simulation notice below each role's card replaces the repeated DEMO badge,
balance qualifiers and routine feedback qualifiers. Practice top-ups and task notices outside
this surface retain their local context. New app-wide typography/palette, issuer logos, card
credentials, randomized reveal motion and cultural-authenticity claims are excluded.
Physical Android and named Arabic/UAE review remain distinct from browser inspection.
